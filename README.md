# VocaLearn

TEPS 어휘 600개를 플래시카드와 퀴즈로 외우는 웹앱입니다. 바로 쓰기: https://baggychani.github.io/VocaLearn/

`index.html`을 브라우저에서 열어도 바로 공부할 수 있습니다. 설치나 서버가 필요 없습니다.

## 단어장 데이터

기본 단어장은 `data/teps_vocab.csv`(TEPS 어휘 600개)입니다. 열은 `id, word, meaning, explanation, category`이고, 화면에 쓰이는 것은 `word`(표제어), `meaning`(뜻), `explanation`(설명), `category`(분류)입니다.

CSV를 고친 뒤에는 아래 명령으로 `words.js`를 다시 만드세요. `index.html`을 파일로 바로 열어도 동작하도록 단어장을 스크립트로 굽는 단계입니다. `words.js`는 직접 고치지 마세요.

```
node scripts/build-words.mjs
```

- 빌드할 때 단어 중복과 칸 수(쉼표가 든 칸은 큰따옴표로 감싸야 함)를 확인하고, 같은 단어족으로 보이는 표제어(abate·abatement처럼 앞 6글자가 같거나 한쪽이 다른 쪽을 품는 경우)는 경고합니다. 확인을 마친 짝은 `scripts/build-words.mjs`의 `ALLOWED_PAIRS`에 적어 둡니다.
- 1–500번은 처음 받은 단어, 501–600번은 추가한 단어입니다. 암기·북마크 기록은 단어와 뜻으로 구분하므로 단어를 더해도 기존 기록이 그대로 남습니다.
- 퀴즈의 오답 보기는 **같은 분류**(동사·형용사·명사·Part I 구어 표현·다의어·Part II)에서만 고릅니다.
- 설명에 `~와 유의어`, `~ 계열`, `~와 같은 뜻`으로 적힌 단어끼리와, 뜻이 겹치는 단어끼리는 한 문제의 보기로 함께 내지 않습니다(정답이 둘이 되지 않도록). `반의어`·`혼동 주의`·`구별`로 적힌 단어는 오히려 좋은 오답 보기라서 그대로 둡니다.
- 단어 가져오기 화면은 데이터베이스를 붙이기 전까지 꺼 두었습니다(`app.js`의 `IMPORT_ENABLED`). 켜면 JSON 배열을 붙여넣을 수 있고, 설명은 `description`이나 `explanation` 어느 이름으로 넣어도 됩니다.

## 학습

- 플래시카드에서 카드를 누르거나 `Space`를 누르면 뜻과 설명이 보입니다. `←`·`→`로 이동하고, `M`으로 암기 완료, `B`로 북마크를 표시하거나 해제합니다(한글 입력 상태에서도 동작). 휴대폰에서는 카드를 옆으로 밀어 넘깁니다.
- 북마크는 외웠는지와 상관없이 따로 모아 볼 단어입니다. 카드 왼쪽 위 표시로도 켜고 끕니다.
- 카드 위 도구: **안 외운 단어만**, **북마크**(둘 다 켜면 북마크 중 안 외운 단어), 순서 섞기(다시 누르면 원래 순서), 단어 목록.
- 필터를 켠 채 암기 완료(또는 북마크 해제)를 누르면 그 카드는 바로 사라지지 않고, 다음 카드로 넘길 때 목록에서 빠집니다.
- 단어 목록 위 검색창에서 영어 단어나 뜻으로 찾습니다. `/`를 누르면 어디서든 검색창으로 가고, `Enter`는 맨 위 결과를 열고, `Esc`는 검색어를 지웁니다.
- 다 외웠으면 **처음부터 다시 외우기**(빈 화면) 또는 암기 현황의 **처음부터 다시**로 암기 표시를 지웁니다. 지운 직후 나오는 **되돌리기**로 취소할 수 있습니다. 북마크는 지우지 않습니다.
- 퀴즈 설정: 문항 수(＋/− 또는 빠른 선택), 문제 유형(혼합·뜻 고르기·단어 고르기), 출제 범위(전체·안 외운 단어·북마크), 시간 제한(없음·문항당·퀴즈 전체). 설정은 브라우저에 기억됩니다.
- 퀴즈 중: `1`–`4`로 보기 선택, `Enter`로 다음 문제, `Esc` 또는 × 버튼으로 끝내고 설정으로 돌아갑니다. ↻ 버튼은 같은 문제로 처음부터 다시 풉니다. 모르면 **잘 모르겠어요**로 답을 바로 확인합니다.
- 답한 뒤에는 모든 보기에 짝이 되는 단어·뜻이 함께 보이고, 정답 단어의 설명이 나옵니다. 오답 보기는 접미사·길이·단어장 위치가 비슷한 단어에서 골라 헷갈리게 냅니다.
- 결과에서 틀린 단어를 확인하고 **틀린 것만** 다시 풀거나, **오답 카드로 복습**하거나, 같은 문제로 **다시 풀기**를 할 수 있습니다.
